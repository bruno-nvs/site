# Portfólio Web - HTML Semântico

Projeto desenvolvido com foco em aprendizado de desenvolvimento front-end, utilizando HTML semântico para construção de uma página pessoal e apresentação de informações profissionais.

O objetivo principal deste projeto foi praticar estruturação de páginas web, organização semântica de conteúdo e criação de uma base sólida para evolução em desenvolvimento web.

---

## Objetivo

Praticar conceitos fundamentais de front-end, incluindo:

- Estruturação semântica em HTML
- Organização de conteúdo
- Navegação interna
- Criação de formulários
- Tabelas e listas
- Boas práticas de acessibilidade
- Estrutura inicial de portfólio profissional

---

## Tecnologias Utilizadas

- HTML5

---

## Funcionalidades

### Navegação
- Menu com navegação interna entre seções
- Links externos com abertura em nova aba

### Sobre
- Apresentação profissional
- Exibição de habilidades e tecnologias

### Projetos
- Sessão dedicada a projetos e aprendizado

### Habilidades
- Tabela organizada com tecnologias e níveis de conhecimento

### Contato
- Formulário de contato
- Links para GitHub e redes profissionais
